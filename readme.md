# ohm-maintenance

## Ambiente de projeto

### Develop
Ambiente de desenvolvimento, onde as novas funcionalidades são criadas e testadas pelos programadores.

### QAS
Ambiente de testes de qualidade (QA), usado para validar se tudo está funcionando antes de seguir adiante.

### Homolog
Ambiente de homologação, onde o cliente ou usuário final válida se o que foi entregue está de acordo com o esperado.

### Production
Ambiente de produção, onde o sistema está no ar e sendo usado de verdade, também é utilizado o nome "main".
